## 评论与处理

| 评论 | 核实与处理 |
|---|---|
| 开发包缺少导入文件 | 实际ZIP根目录和training目录均有文件。补全材料后Claude撤回；打包器增加副本一致性检查。 |
| 训练依赖缺timm | 已补齐timm、safetensors等依赖及安装检查。服务器完成真实样本的优化器更新与EMA更新。 |
| 推理配置与训练缓存可能错配 | 配置由缓存清单生成，检查检测器SHA；权重目录存在训练metadata时核对缓存SHA。 |
| 本地提交检查仅验证结构 | 增加真实样本执行，解压ZIP后载入权重，核对40个有限预测分数。 |
| B与T的来源 | B取冻结baseline在组织方测试集上的准确率；T取同一GPU、同一完整runner对公开验证集三次平均延迟的中位数。 |
| 旧手写实验配置可能误导 | 从开发包移除，README改用配置生成脚本。 |
| 预训练权重路径阻断队列 | 服务器实际检查发现符号链接指向任务目录外；将权重复制至授权目录并核验SHA，训练已恢复。 |

## 服务器实测

学生开发包以真实2段训练样本、1段验证样本完成：清单读取、缓存构建、公开预训练载入、反向传播、EMA更新、权重保存、推理配置生成、代码打包和解压后预测。缓存与推理输入逐元素一致，输出40类分数。

16帧深度＋IR、YOLO裁剪＋R(2+1)D-34已完成30轮。A100 40GB上的训练及验证耗时约14.2分钟，峰值训练显存约9.73GiB；缓存准备另耗时约16.4分钟。最终导出权重在466段公开验证集上的FP32准确率为64.59%，Macro F1为57.69%；训练期间最佳验证准确率为67.17%。分类器与检测器合计66.14M参数。

该导出版本完成8段公开验证样本的隔离runner验收，包含图像处理、检测和分类的平均耗时约412ms/片段。此项记录使用本地预置只读权重。三组实验已完成，推荐16帧全图版本；汇总见实测记录与A100标定记录。

## 成绩构成

用户最终确认：客观测评50分、技术报告10分、现场答辩40分。计分PDF中的项目成果分采用百分制，乘50%计入总分。

报告分项沿用原三份赛题说明：方案与关键设计30%、实现及复现30%、结果与局限分析30%、引用与团队贡献10%。现场答辩为方案介绍30%、运行演示30%、现场问答40%。

平台保持第一阶段60%／答辩40%的结构，第一阶段内部使用5/6和1/6。已调用实际计分函数验证：三项分别满分时贡献50、10、40分；客观81、报告80、答辩90时，总分84.5。
