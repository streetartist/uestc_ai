# 题目统一 AutoDL 算力额度

## 算力渠道接入边界

用户要求渠道具有与 AutoDL 相当的官方 API 管理能力：实例创建、开关机、状态查询及连接信息，测评须使用受信任的环境与指标采集。不能用 Notebook 链接登记、手动导入报告或自建模型 HTTP 地址代替实例管理。2026-10-05 移除未满足此要求的三平台 Notebook 入口，界面只展示实际实现的 AutoDL Pro；今后先确认完整官方协议和可验证的测评链路，再开放新渠道。

[Kaggle 官方命令](https://github.com/Kaggle/kaggle-cli/blob/main/docs/kernels.md)支持 Notebook 提交运行、状态与产物，不据此声明支持 AutoDL 式实例开关机/SSH。补充核对发现，Colab 已有[官方运行时 API](https://developers.google.com/colab/api/reference/rest)，支持创建、查询、列举和删除运行时，但文档注明 Beta、需项目白名单授权；[官方 CLI](https://github.com/googlecolab/google-colab-cli)还声明创建/停止运行时、代码执行、文件传输和 SSH（当前只支持 Linux/macOS）。不能再断言 Colab 没有实例管理 API；普通免费账号的资格、调用权限与稳定性尚未实测，[FAQ](https://research.google.com/colaboratory/faq.html)仍列有免费运行时 SSH/分布式节点限制，开放新渠道前需核对其与新 API 的适用关系。Colab Enterprise 另有 GCP 实例管理 API，不等同于普通免费账号。ModelScope 有模型推理 API，社区免费 Notebook 的实例创建/开关机/SSH 管理 API 尚未确认；PAI DSW 的收费 API 不代表该免费服务。未完成账号权限与实际接入验证的平台暂不列为可用渠道。

## 使用入口

1. 管理员在 `/api-platform` 的“算力渠道”添加 AutoDL 容器实例 Pro 渠道：填写名称、开发者 Token、整实例预算单价，下拉选择 GPU 型号、卡数、运行镜像和 CUDA 下限，勾选允许地区。Token 使用现有 `AI_GATEWAY_ENCRYPTION_KEY` 加密，保存后不返回明文。组织者可查看渠道，不可修改账号凭据。
2. 在题目编辑页的“环境与资源”统一设置 Docker 测试环境、模型 API 和每队 GPU 卡时、参考运行费用上限，支持[整包导入](problem_packages.md)。模型 Token 与 GPU 预算独立，已有队伍统一应用、新队伍自动继承，每队各自扣减。
3. 参赛成员在“算力实例”选择本次运行分钟数，创建并开机、再次开机、提前关机或查看 SSH 连接。每队每题持有独立实例，停止后保留文件。不同队伍不能访问对方实例；评委只可查看获分配赛事的用量、状态与最近记录。
4. 实例卡片显示 JupyterLab、AutoPanel、实例监控和自定义服务。运行时本队成员及管理员可使用，关机/停用后禁用。JupyterLab 和 AutoPanel 在点击时重新核对权限、运行状态和截止时间，再跳转到最新上游地址；工具 Token 不进入概览、记录或数据库。CPU、内存、系统盘/数据盘快照及 6006/6008 服务信息按需读取，详情一分钟后隐藏；HTTP 服务可直接打开，TCP 显示客户端连接地址。映射入口不代表实例内应用已经启动。

### 工具协议约束

- `POST /compute/instances/<id>/tools` 只返回白名单监控字段、自定义服务地址和工具可用标记，不返回开发者 Token、SSH 密码或 Jupyter Token；响应 `Cache-Control: no-store`。仅本队当前成员及管理员可读，组织者及评委无跨队工具权限。查询结束后再次校验权限、停止请求及截止时间。
- `GET /compute/instances/<id>/tools/jupyter|autopanel` 私有跳转禁止缓存和传递 Referrer。核对 2026-10-05 的 AutoDL 官方网页公开工具逻辑：JupyterLab 使用 `/jupyter?token=...`，AutoPanel 与完整监控共用 `/?token=...`，Token 使用 URL 编码。`jupyter_port == 0` 使用 `https://jupyter_domain`，非零端口使用上游代理主机与对应端口；6006/6008 映射也按此规则构造。地址只接受 AutoDL 已确认的 `autodl.com`、`seetacloud.com`、`gpuhub.com` 子域，拒绝 userinfo、路径注入和非官方主机，不从选手输入构造跳转。
- 实测 Pro 快照的 `usage_info.valid` 为 false 时仍返回 CPU、内存和磁盘样本；此未文档化字段不作为样本就绪依据。展示类型、范围均有效的字段，按 `valid_at` 标注采样时间；超过两分钟、未来超过三十秒或未提供带时区时间的快照标记为旧数据。CPU 为上游原始用量（可超过 100%，快照未提供 CPU 核数，未做整机归一化）。GPU 利用率不在 Pro 快照中，完整监控通过 AutoPanel 查看，不编造 GPU 指标。

### 渠道选项与镜像

`GET /compute/manage/options` 提供 2026-10-05 核对的 Pro 官方附录卡型和公共镜像、官方示例地区。它是配置目录，不是实时库存或价格查询。公共镜像自动填写驱动支持的 CUDA 版本下限，管理员可以再调整；卡数为官方允许的 1–4 张。目录外卡型、镜像保留自定义入口，编辑旧渠道保留已有编号和地区，原保存接口字段不变。

管理员可点击“读取账号私有镜像”，通过 `POST /compute/manage/private-images` 请求官方只读列表，分页读取并显示镜像是否就绪；尚未就绪的镜像不可选。支持当前表单 Token 或渠道已保存凭据，表单 Token 仅用于此次内存中的请求，读取不会保存或替换凭据、创建实例；响应禁止缓存并仅返回镜像编号、名称和就绪状态。无私有镜像时仍可选公共镜像。组织者、评委及参赛成员不能调用该凭据读取入口。

## 部署

```powershell
# 使用与 Web API 相同的 DATABASE_URL、AI_GATEWAY_ENCRYPTION_KEY
python -m flask --app backend/app.py db upgrade
python backend/compute_worker.py
```

生产环境须将独立 `compute_worker.py` 作为受进程管理器监管的常驻服务，与 Web 服务一起启动，并监控进程、数据库与外网连通性。运行端每轮续期 45 秒的数据库心跳；没有有效心跳时拒绝新的开机请求，页面显示离线。持久化请求有 300 秒领取租约，工作进程崩溃后可由恢复的进程接续核对。Web 服务重启不会丢失已提交的关机请求或运行记录。

默认仅允许官方 `https://api.autodl.com`，拒绝跳转。`COMPUTE_ALLOW_LOCAL_HTTP=1` 仅用于回环 HTTP 模拟服务测试；生产保持关闭。不要改变加密密钥，否则现有 Token 无法解密；重新填写 Token 前须恢复或迁移原密钥。

## 额度与计量约束

- 配置按题目统一，额度变更保留各队实例、记录、计数。低于任何队伍已用或预占量的修改整体拒绝。已有实例后不能换本题渠道，渠道也不能修改镜像、卡型或卡数。可以修改名称、凭据、启用状态和之后开机使用的预算单价。
- GPU 卡时 = 卡数 × 发起开机到确认关机的秒数 / 3600。计时覆盖启动、状态核对和关机等待，按分配时长计量，不依赖选手 GPU 利用率或 SSH 内进程。每次开机预占 `(计划秒数 + 30 秒关机余量) × GPU 数量`；实例整机费用按渠道预算单价预占。预占失败不会触发上游请求，同队同题只能有一个未结算的会话。
- 开机请求携带队伍范围内唯一 `request_id`；重复请求返回原会话，不重复扣减或创建。请求在调用上游之前持久化为“创建/开机中”；创建响应丢失时按固定名称查找已有实例，不重放创建或开机请求，避免重复收费。列表核对最多扫描 500 个实例，超出时保留预占并提示管理员核对。
- 到计划关机时间、题目/渠道停用，或检测到价格未知/超过预算单价时，运行端请求关机。关机失败继续重试；必须取得上游停止状态后才按已用秒数结算并归还未用预占。长时间上游故障可能超过 30 秒余量；如果结算超出额度，本队本题停用。不能把本地额度视为 AutoDL 账号账单的绝对封顶。
- 参考运行费用使用整数毫元，按配置的整实例预算单价估算，最低一次 0.01 元。发现快照价格高于预算单价时按更高单价估算并请求关机。此数值不是官方账单，也不含磁盘、文件存储或外部账号操作费用。正式接入必须用实际账号核对 `payg_price` 的多卡含义与单位；如果单卡计价，组织方须按整实例总价配置预算单价后再开放资源。
- 实例启动命令中附加定时关机作备用；SSH 用户具有 root 权限可改变实例内命令，因此独立运行端是主要关机机制。若运行端或上游持续不可用，组织方须在 AutoDL 控制台确认状态并关机；恢复运行端后继续核对。根权限下已读的密码不会因平台撤销队员身份而在实例内失效，变更成员权限时还需在 AutoDL 侧轮换密码/SSH 公钥。
- SSH 密码只在本队当前成员/管理员主动查看时临时返回，响应禁止缓存；前端一分钟后清除，记录和概览不保存或返回密码。组织者可以请求停机，不能查看不属于自己的队伍密码。渠道 Token 不发给选手。
- 取消尚未派发的开机请求可直接退还预占。派发结果不明、固定名称查不到或账号拒绝请求时不会擅自重放收费操作；管理员先核对 AutoDL 账号与实例记录。暂未提供人工退款或绑定实例入口，防止未经证实的退款和错误跨队绑定；不明请求保持锁定，可通过恢复凭据、检查既有实例和联系上游确认后由运维审计处理。
- 不自动释放实例或删除选手文件。已有实例/使用记录时禁止删除队伍、题目和赛道；采用归档保留凭据关联及计量历史。关机数据受 AutoDL 保留周期约束，不保证永久保存。

## 官方协议与验证记录（2026-10-05）

实现依据 [AutoDL Pro 官方 API](https://www.autodl.com/docs/instance_pro_api/)：原始 `Authorization` Token（不加 Bearer）、创建、开/关机、状态、详情、列表。真实服务的详情和状态 GET 必须通过 URL 查询参数传入 `instance_uuid`，不发送请求体；文档将其展示为 Body，但实际返回 `RequestParameterIsWrong`，会使已成功开机的会话一直处于待确认。渠道“测试连接”只读取实例列表，不创建或开机。产品区别见 [容器实例 Pro](https://www.autodl.com/docs/instance_pro/)，计费规则见 [充值与计费](https://www.autodl.com/docs/price/)。

本地模拟使用真实回环 HTTP 服务，验证额度隔离、新队伍继承、并发/幂等预占、不足拒绝、取消退款、主动/到时关机、故障恢复、响应丢失避免重复创建、保留预占、价格超标关机、权限与密码隔离、渠道加密、资源生命周期和迁移回滚保护。38 项算力行为测试和先前的 1 项迁移测试通过；当前结果见 `outputs/compute-tools-tests.log`，新增工具路径/Token 编码、敏感字段隔离、权限撤销/停止/截止时间校验、危险地址拒绝、TCP/直连端口和监控样本年龄。HTTP 模拟服务严格要求 GET 查询参数并拒绝请求体，验证已运行实例从查询拒绝恢复、清除旧错误、且不重复创建或开机。选择配置传到上游、私有镜像分页/空列表/权限/凭据不落库也包含在内。完整后端测试历史结果见 `outputs/compute-full-backend-tests.log`（私有 MC 场景测试跳过）。前端构建和 ESLint 通过。全仓 TypeScript 检查仍有既有 `db/index.ts` 的 Cloudflare/D1 缺失类型问题；现有前端首页测试有一项入口提示文案断言失败，均不是算力改动所涉文件。
