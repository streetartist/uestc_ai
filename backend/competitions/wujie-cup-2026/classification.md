## 任务背景与目标

人体行为识别是智能家居、健康监测与人机交互中的重要技术。本赛题使用 CUHK-X 人体活动数据中的深度图像等非RGB数据，训练能够识别 **40类日常动作** 的分类模型，引导学生完成数据处理、特征提取、模型训练与效果验证。

参赛者可以研究视频时序信息、模型结构、数据增强和轻量化设计，在识别准确率、计算量与处理速度之间取得平衡。禁止使用RGB图像或测试集标签开展训练、调参或人工修正预测。

## 数据与开发环境

正式数据下载方式、授权范围、40类映射、非RGB模态范围、训练/验证/测试划分和推理输入格式，由组织方在正式开赛前公布。测试集标签由组织方保管；所有队伍使用一致的划分和测评规则。

数据来源：[CUHK-X 官方项目](https://github.com/openaiotlab/CUHK-X)及[官方挑战赛](https://openaiotlab.github.io/CUHK-X-Challenge/)。目前平台尚未安装本届正式测试集与可信推理镜像，**本题尚未开放自动指标测试**。原赛事成绩、样例数据结果不得替代本届独立测评。

队伍可以自行配置训练环境；如提供统一GPU资源，其可用类型与每队额度会在本题环境设置中统一公布。

## 提交材料

1. 训练与推理代码 ZIP：包含依赖、预处理流程、训练入口、推理入口及运行配置；不得包含测试标签、账号密钥或原始授权数据。
2. 模型权重下载地址：提供可供组织方获取的固定版本权重、文件大小和 SHA-256，避免平台单附件20MB限制。必须保持有效至评测结束。
3. 预测结果 CSV：按公布的样本ID和类别映射提交，不得漏行、重复ID或包含非法类别。
4. 完整研究报告 PDF：方法设计、训练设置、实验结果、消融实验、效率分析、改进分析与引用。
5. README 与运行说明：软硬件版本、依赖安装、随机种子、训练/推理命令、权重校验和、预测文件结构及复现步骤。

正式推理协议公布后，将同步固定程序包入口与CSV列定义，不预先要求与未发布数据格式不一致的接口。

## 评测与评审

可信测评计划输出识别准确率、Macro F1、推理延迟和资源使用；计算量与模型规模需提供可复现分析，不能只填写自报数字。准确率、计算量与速度之间的具体换算及测评硬件，将在正式开赛前确定。

第一阶段 = 模型实际表现 ×80% + 研究报告 ×20%；最终成绩 = 第一阶段 ×50% + 现场答辩 ×50%。实际表现依据统一测试结果评审，研究报告考察方法设计、实验分析与结果论证。各赛道独立排名。

## 学习与诚信要求

基线、培训录像和参考资料待发布。允许使用公开论文与开源工具，须注明来源和修改内容；不得抄袭、使用泄露标签或伪造实验结果，违规取消获奖资格。
