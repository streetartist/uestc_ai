# 技术报告

技术报告占最终成绩10%。评分包括方案设计30%、实现与复现30%、结果与局限分析30%、引用与团队贡献10%。

## 方案概述

介绍策略或 Agent 的结构、使用的模型，以及自己的主要改动。说明图像处理、定位、规划、动作技能、记忆和验证模块之间的数据流。

## 输入与资源

列出实际使用的观察字段，说明模型、权重、公开演示数据、标定参数和技能常数的来源。训练数据与测试时输入分别交代；涉及公开环境生成的数据时，附上生成脚本和配置。

## 运行配置

记录代码版本、模型名称、thinking 设置、输出上限、依赖和复现命令。提交 ZIP 的 SHA256 与关联的官网自测记录编号一并填写。

## 实验设置

列明任务、公开初态、控制步数和调用预算。比较不同方法时采用相同场景、观察和预算，记录各版本的具体改动。

## 研究发现

记录研究问题、尝试的方法、实验现象及结论。与已有方法比较、验证失败原因、分析泛化或效率都可以作为研究内容。答辩可汇报相关发现。

## 引用与团队分工

列出使用的模型、开源代码和数据来源，标明自己的修改与各成员贡献。补充权重或数据时给出版本、获取方法和校验值。
